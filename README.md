# PARTAW DIGITAL
React + Vite starter for PARTAW DIGITAL — “A Brighter Digital Future”.

## Run locally
Install Node.js LTS, open a terminal in this folder, then:
```bash
npm install
npm run dev
```
Use the local URL printed by Vite (usually http://localhost:5173).

## Build and test
```bash
npm run build
npm run preview
```
The production output is written to `dist/`.

## Before publishing
- Replace the founder portrait placeholder with an approved photo and verified biography.
- Replace generic social links with official PARTAW DIGITAL profiles.
- Set the WhatsApp contact link to the actual business number or wa.me link.
- Add real portfolio projects when ready.
- Have the Dari and Pashto text reviewed by fluent speakers.
- Run the production build and test mobile, desktop, all language directions and all links.

## Deploy
Upload the files to a new GitHub repository, import it into Vercel, use build command `npm run build` and output directory `dist`. Vercel normally detects Vite automatically.

This is a new project and does not depend on EVOLVIA.
